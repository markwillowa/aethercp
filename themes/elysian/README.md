# Elysian Mythic Theme for AetherCP

Elysian Mythic is an official celestial theme for AetherCP.
It builds upon the Aether theme engine with:
- Sapphire and Golden accent palettes
- High-contrast typography optimized for high-resolution displays
- Full mobile and tablet responsive layouts
- Seamless integration with AetherCP's modular components

## Activation
Administrators can activate this theme instantly in the **Admin Control Panel > Theme Manager**.
