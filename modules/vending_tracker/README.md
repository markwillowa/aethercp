# Vending & Market Tracker Module for AetherCP

This extension module adds in-depth vendor search, live merchant shop indexing, and market economy monitoring to AetherCP.

## Features
- Real-time indexing of `vendings` and `vending_items` emulator tables.
- Filter by item name, refine level, card slots, and merchant map coordinate.
- Vendor location map pin in Prontera and major market hubs.
